# Writing Plans Lite

## Uso

Cuando una tarea tiene multiples pasos, archivos o riesgos, y conviene separar decisiones de ejecucion.

## Proceso

1. Definir objetivo en una frase.
2. Mapear archivos a crear o modificar.
3. Dividir en tareas pequenas verificables.
4. Incluir comandos de prueba esperados.
5. Guardar plan en `docs/superpowers/plans/` si el trabajo no cabe en una respuesta breve.

## Reglas

- Sin `TODO`, `TBD` ni instrucciones vagas.
- Cada tarea debe tener un entregable visible.
- Si hay partes independientes, marcar candidatas para subagentes.

## Salida

- Plan breve o archivo de plan.
- Checklist de ejecucion.
- Criterios de verificacion.
