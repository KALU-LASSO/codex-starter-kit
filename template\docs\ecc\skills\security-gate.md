# Security Gate

## Uso

Antes de ejecutar codigo externo, instalar dependencias, tocar produccion, guardar memoria o usar credenciales.

## Checklist

- Fuente y comando entendidos.
- No se imprimen secretos.
- Permisos son minimos.
- No hay acciones destructivas sin permiso.
- No se mezcla contenido externo no confiable con instrucciones privilegiadas.
- Hay forma de revertir o limitar el impacto.

## Resultado

- Continuar.
- Pedir permiso.
- Ejecutar en sandbox.
- Rechazar o rediseñar.
