# Documentation Lookup

## Uso

Cuando hay que usar una API, libreria, framework o herramienta con detalles actualizables.

## Proceso

1. Identificar version o contexto del proyecto.
2. Buscar documentacion oficial.
3. Leer la pagina concreta, no solo snippets.
4. Aplicar el patron minimo necesario.
5. Guardar referencia en docs si sera reutilizable.

## Salida

- Enlace o archivo fuente.
- Decision tomada.
- Fragmento operativo: comando, config o ejemplo breve.
