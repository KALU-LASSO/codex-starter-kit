# Agent Rules

- Codex coordina; el usuario no debe tener que gestionar subagentes.
- Briefings cortos: objetivo, contexto, alcance, limites, entregable.
- No heredar contexto completo si un subagente puede trabajar con contexto minimo.
- No asignar a dos subagentes el mismo archivo si van a editar.
- Revisar y verificar resultados de subagentes antes de integrarlos.
- Delegar dominios, no tareas vagas.
- Si la siguiente accion del hilo principal depende del resultado, hacerlo localmente.
