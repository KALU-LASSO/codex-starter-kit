# Executing Plans Lite

## Uso

Cuando ya existe un plan y toca implementarlo con checkpoints.

## Proceso

1. Leer el plan completo.
2. Señalar dudas o riesgos antes de tocar codigo.
3. Ejecutar una tarea o bloque coherente cada vez.
4. Verificar cada bloque.
5. Actualizar estado del plan si procede.

## Reglas

- No forzar ejecucion si el plan tiene huecos criticos.
- No cambiar el alcance sin avisar.
- Mantener cambios pequenos y verificables.

## Salida

- Cambios aplicados.
- Verificacion por bloque.
- Pendientes o bloqueos.
