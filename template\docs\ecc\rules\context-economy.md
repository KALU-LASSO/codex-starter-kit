# Context Economy Rules

- Leer primero indices, READMEs y mapas; abrir detalles solo cuando sean relevantes.
- No cargar bibliotecas enormes de skills por defecto.
- Mantener `AGENTS.md` corto y usar `docs/` bajo demanda.
- Para repos grandes, buscar con `rg` antes de leer archivos completos.
- Resumir memoria en `docs/memory/index.md` y abrir observaciones concretas.
- Evitar repetir contexto estable en cada prompt; convertirlo en archivo.
- Usar subagentes solo para trabajo independiente.
- Mantener bajo el numero de herramientas/conectores activos cuando no sean necesarios.
