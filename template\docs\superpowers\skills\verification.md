# Verification Before Completion

## Uso

Antes de afirmar que algo esta terminado, arreglado, pasando o listo.

## Proceso

1. Identificar que comando, prueba o revision demuestra la afirmacion.
2. Ejecutar verificacion fresca.
3. Leer salida y codigo de salida.
4. Reportar el estado real.

## Evidencia Segun Caso

- Tests: comando y resultado.
- Build: comando y salida sin errores.
- Bug: pasos del fallo original y resultado actual.
- UI: captura o revision en navegador si aplica.
- Docs/memoria: archivos creados y busqueda o lint basico.

## Reglas

- No decir "listo" sin evidencia.
- No extrapolar desde una prueba parcial.
- Si no se pudo verificar, decirlo claramente.
