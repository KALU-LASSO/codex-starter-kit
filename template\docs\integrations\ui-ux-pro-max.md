# UI UX Pro Max

Use this runbook when Codex needs UI/UX design guidance, audits, design tokens, accessibility checks, or structured design-system output.

## Suggested Use

- Generate a design system before building a new UI.
- Review UI against accessibility, responsive, interaction, and visual quality criteria.
- Use structured JSON contracts for API-oriented design work.

## Safety

- Do not copy upstream repos wholesale into product projects unless needed.
- Attribute upstream inspiration.
- Validate JSON schemas and OpenAPI contracts when exposing API surfaces.
