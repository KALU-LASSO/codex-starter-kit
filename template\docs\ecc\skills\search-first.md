# Search First

## Uso

Cuando una respuesta depende de docs, API, libreria, repo o comportamiento que puede haber cambiado.

## Proceso

1. Buscar fuente primaria o archivo local relevante.
2. Abrir solo los resultados candidatos.
3. Extraer hechos accionables.
4. Citar fuentes si vienen de web.
5. Separar hechos de inferencias.

## Adaptacion Codex

- Para OpenAI, usar documentacion oficial y skills disponibles.
- Para codigo local, usar `rg`/`rg --files`.
- Para web, priorizar repos, docs oficiales y fuentes primarias.
