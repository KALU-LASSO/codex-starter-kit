# Agent Profiles

Estos perfiles son briefings reutilizables para Codex y sus subagentes. No son prompts largos para copiar sin pensar: son criterios de trabajo.

## Como Usarlos

- Para una tarea directa: "usa el perfil `cms-developer` y revisa este WordPress".
- Para trabajo paralelo: "lanza subagentes con `paid-media-auditor`, `tracking-measurement-specialist` y `seo-specialist`".
- Para crear una memoria de proyecto: copiar solo los perfiles utiles al proyecto o referenciarlos desde el `AGENTS.md` del repo.

## Formato

Cada perfil contiene:

- Mision
- Cuando usarlo
- Reglas criticas
- Entregables
- Checklist
- Briefing sugerido para subagente
