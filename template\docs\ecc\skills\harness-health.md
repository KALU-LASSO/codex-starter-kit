# Harness Health

## Uso

Cuando el trabajo se vuelve lento, caro, confuso o demasiado cargado de contexto.

## Checklist

- Hay demasiados documentos abiertos o instrucciones redundantes.
- Se estan usando conectores que no aportan a la tarea.
- La memoria contiene duplicados u observaciones obsoletas.
- La tarea deberia dividirse en partes independientes.
- Falta una regla corta en vez de repetir prompts largos.
- El router no sugiere el perfil adecuado.

## Acciones

- Resumir y archivar contexto estable.
- Actualizar `AGENTS.md` o `docs/memory/`.
- Desactivar o ignorar herramientas no necesarias.
- Crear un perfil de agente si una especialidad se repite.
