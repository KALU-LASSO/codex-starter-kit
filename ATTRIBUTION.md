# Attribution

This starter kit contains local, curated adaptations inspired by the following open-source projects:

- `msitarzewski/agency-agents`: agent profile structure and agency-role inspiration.
- `thedotmack/claude-mem`: persistent memory concepts, adapted into lightweight Markdown memory.
- `obra/superpowers`: development workflow ideas for planning, TDD, debugging, verification, and review.
- `affaan-m/everything-claude-code`: portable rules for security, context economy, agents, and harness health.
- `nextlevelbuilder/ui-ux-pro-max-skill`: UI/UX design intelligence integration patterns.
- `czlonkowski/n8n-mcp`: n8n workflow building and MCP operation patterns.
- `nidhinjs/prompt-master`: prompt routing, prompt repair, and token-efficiency patterns.

No upstream repository is vendored wholesale in this kit. The files in `template/` are local adaptations intended for Codex project setup.
